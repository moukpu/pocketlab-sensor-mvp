# PocketLab STEM

Телефон, ноутбук и обычный маятник — уже маленькая лаборатория. PocketLab передаёт показания датчиков телефона на экран ноутбука, помогает изучать движение и звук, а результаты можно сохранить и разобрать позже.

## Что можно сделать

- Посмотреть, как телефон ускоряется и поворачивается, и увидеть показания на графиках и в 3D.
- Закрепить телефон на маятнике, измерить его период и оценить ускорение свободного падения по длине подвеса и результатам измерения.
- Исследовать звук с помощью микрофона телефона: посмотреть на частоту, громкость и форму сигнала.
- Повторять опыты с разной длиной маятника, сравнивать серии и сохранять данные в JSON или CSV.

## Как подключить телефон

Откройте PocketLab на ноутбуке, создайте сеанс и отсканируйте QR-код телефоном. После подключения разрешите доступ к датчикам кнопкой на странице телефона. Для опыта со звуком отдельно разрешите доступ к микрофону.

На компьютере приложение открывается по адресу http://localhost:3000. Телефон не сможет подключиться к адресу localhost на ноутбуке: ему нужен защищённый HTTPS-адрес. Для быстрой проверки можно использовать временный Cloudflare Tunnel.

## Запуск на своём компьютере

Нужны Node.js 22.12 или новее и npm. Откройте PowerShell в папке проекта и выполните:

~~~powershell
npm ci
npm run dev
~~~

Страница ноутбука откроется на http://localhost:3000. Если сервер уже запущен, не запускайте второй экземпляр на том же порту.

### Проверка на телефоне через временный HTTPS-адрес

Установите Cloudflare Tunnel, если его ещё нет:

~~~powershell
winget install --id Cloudflare.cloudflared --exact --accept-source-agreements --accept-package-agreements
~~~

Соберите и запустите приложение в одном окне PowerShell:

~~~powershell
npm run build
npm start
~~~

Во втором окне запустите туннель:

~~~powershell
cloudflared tunnel --url http://localhost:3000
~~~

Откройте выданный адрес вида https://…trycloudflare.com на ноутбуке, создайте сеанс и отсканируйте QR-код. Туннель должен работать всё время опыта. Это временный адрес для проверки, а не постоянный хостинг.

## Данные и ограничения

Показания датчиков передаются с телефона на ноутбук через WebSocket-реле. Реле пересылает данные и не сохраняет записи. Сама запись остаётся в памяти вкладки ноутбука — скачайте JSON до перезагрузки страницы или начала новой записи.

В опыте со звуком исходная аудиозапись не сохраняется. Во время измерения на ноутбук передаются компактные данные для анализа звука, включая короткое представление сигнала.

PocketLab — учебный прототип, а не поверенный измерительный прибор или готовый публичный сервис с учётными записями. Точность зависит от телефона и установки опыта. Автоматические проверки помогают находить ошибки в коде, но не заменяют проверку с настоящими устройствами.
